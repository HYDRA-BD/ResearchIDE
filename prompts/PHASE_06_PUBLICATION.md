# PHASE 6 — ACADEMIC TEMPLATES AND PUBLICATION PREPARATION

Implement the publication preparation subsystem.

## 1. Template library

Support templates for:
- IEEE.
- Springer Nature.
- Elsevier.
- ACM.
- Wiley.
- APA.
- Other compatible publishers and academic institutions.

Support exact journal, conference and university templates when available.

## 2. Template acquisition

Allow users to:
- Import local templates.
- Download templates when internet access is available.
- Cache downloaded templates.
- Use cached templates offline.
- Inspect template metadata.
- Preserve the template version used by existing projects.

Clearly distinguish official publisher templates from community-created templates.

## 3. Template application

Apply supported formatting rules to manuscripts.

Preserve:
- Document content.
- Citations.
- Bibliographic records.
- Figures.
- Tables.
- Equations.

Do not silently discard unsupported formatting.

## 4. Formatting verification

Check:
- Page limits.
- Margins.
- Font sizes.
- Required sections.
- Title formatting.
- Abstract length.
- Keywords.
- Figure captions.
- Table captions.
- Bibliography formatting.
- Reference consistency.

Distinguish verified requirements from requirements that could not be checked automatically.

## 5. Submission preparation

Generate:
- Final PDF.
- LaTeX source package.
- Submission checklist.
- Title page where required.
- Abstract.
- Keywords.
- Supplementary material organization.

## 6. Submission checklist

Provide a report showing:
- Passed checks.
- Failed checks.
- Warnings.
- Manual verification requirements.

Do not claim that a manuscript is guaranteed to be accepted.

## 7. Testing

Test with representative templates and sample manuscripts.

Verify that switching templates does not corrupt references, figures, equations or document content.

## 8. Completion

The user must be able to prepare a manuscript for a selected publication target and export the required submission materials.
